# DSA 2026 - Time-Travel Debugger

Project 01 for Data Structures and Algorithms.

The project implements the server-side phase of a Time-Travel Debugger using custom data structures, program execution tracing, snapshots, and binary serialization.

## Phase 01 Pipeline

1. Pass 0x0 - Validation
2. Pass 0x1 - Resolve
3. Pass 0x2 - Execution
4. Pass 0x3 - Serialization
